# Commit Style

As of the introduction of this file, commits to the repository must be in the following format:

- the title needs the format `<subject>: <title>` (e.g. `jjfold: add initial property tests`)
- the title must be <=50 characters total
- there must be a description

Ideally, the `<title>` after the `<subject>` starts with a present tense verb as well (e.g. `add`,
`delete`, `ensure`, `enforce`, `modify`).
